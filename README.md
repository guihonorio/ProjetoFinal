# Sistema de Pagamentos e Gestão para Lojas

Sistema de pagamentos e gestão para lojas, desenvolvido em Java utilizando conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades

- Sistema de login para funcionários;
- Cadastro, alteração e listagem de funcionários;
- Gerenciamento de Gerentes e Operadores de Caixa;
- Abertura e fechamento do caixa;
- Realização de pagamentos;
- Pagamentos via PIX, Boleto, Cartão de Débito e Cartão de Crédito;
- Listagem de pagamentos;
- Relatório de vendas com total das vendas realizadas.

## Tecnologias Utilizadas

- Java 17+
- Apache NetBeans
- Git e GitHub

## Como Executar

### Pré-requisitos

É necessário ter o **JDK 17 ou superior** instalado.

### Pela IDE

1. Clone o repositório:

   git clone https://github.com/guihonorio/ProjetoFinal.git

2. Abra o projeto no Apache NetBeans.
3. Execute a classe principal do sistema.

### Pelo Terminal

Na raiz do projeto, execute:

    javac -d out src/loja/*.java

Depois:

    java -cp out loja.Main
